# Control 安全边界

源码公开不提供云端管理凭据、数据库、项目记忆、源站部署地址或私钥。发布从严格允许列表导出并扫描；个人数据、环境文件、测试回执、运维配置与构建签名密钥不进入公开仓库或安装包。

官网经 CDN/WAF 回源。源站只接受配置的可信边缘网络，依据 TCP 对端地址判定；应用仅从精确指定的内部代理接受访客地址。禁止信任任意来路的 X-Forwarded-For、X-Real-IP 或客户端角色标记。登录桥独立端口只允许指定身份服务主机，网络层同时覆盖 Docker 转发和主机 INPUT、IPv4/IPv6。

官网分离登录、反馈、下载、更新流量的请求和连接预算，并设置全局并发、响应超时、请求正文上限、账号配额、下载速率及匿名拒绝。应用有界线程/内存限流在数据库前生效，容器使用非 root、只读根文件系统、删除 capabilities、禁止提权和资源限制。TLS 握手放在有界工作线程，避免慢连接阻塞接受循环。

反馈私密且按账号隔离，专用凭证仅可创建工单，不能管理账号或执行代码。完整合同见 `docs/FEEDBACK.md`。维护人员只能通过服务器受控 Shell 处理；反馈正文视为非可信数据。

这些措施降低应用层 CC 和绕过 CDN 的风险。共享服务器历史地址无法保证永不被发现，网络链路被大规模 DDoS 打满仍依赖 CDN/托管商的清洗容量与上游 ACL；不能承诺绝对不可攻击。源站迁移、IP 轮换、CDN 套餐或 DNS 变更需要按现有基础设施配置验证。

部署升级必须保留旧容器和配置副本，先验证登录、下载、更新与反馈，再切换；不覆盖已签名的历史制品。报告安全问题请使用官网私密反馈，不在公共聊天室粘贴漏洞细节或凭据。
